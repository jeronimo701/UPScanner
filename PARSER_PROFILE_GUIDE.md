# Профили парсинга (инструкция)

Этот файл объясняет, как создавать и использовать профили разбора документов в UP Scanner.

## 1. Что такое профиль парсинга

Профиль парсинга - это набор правил, по которым программа извлекает из PDF/XLS/XLSX:

1. номер документа;
2. дату документа;
3. код позиции;
4. название позиции;
5. количество;
6. комментарии (для Excel).

Текущий активный профиль выбирается в интерфейсе:
`Меню настроек -> Профиль разбора`.

Выбранный профиль сохраняется между перезапусками.

## 2. Где лежат файлы профилей

Рядом с `UPScanner.exe`, в папке `data`:

1. `data/parser_profiles.json` - список доступных профилей;
2. `data/active_parser_profile.json` - активный профиль.

Если `parser_profiles.json` отсутствует или поврежден, используется встроенный профиль `poscenter`.

## 3. Формат файла parser_profiles.json

Это JSON-объект, где ключ верхнего уровня - имя профиля:

```json
{
  "poscenter": {
    "label": "POScenter",
    "description": "Базовый профиль для текущих выгрузок POScenter/УП.",
    "code_pattern": "^(?:УП-\\d{8}|\\d{6,})$",
    "doc_pattern": "(?:№\\s*)?(УП-\\d+).*?(?:от\\s+(\\d{2}[.\\s]\\d{2}[.\\s]\\d{4}|\\d{1,2}\\s+[А-Яа-я]+\\s+\\d{4}))",
    "row_start_pattern": "^(\\d+)\\s+((?:УП-\\d{8})|(?:\\d{6,}))\\s*(.*)$",
    "qty_pattern": "(.+?)\\s+(\\d+(?:[,.]\\d+)?)\\s*шт(?:\\s|$)",
    "stop_prefixes": ["Итого", "Сдал:", "Принял:"],
    "excel_headers": {
      "code": ["код товара", "артикул", "код"],
      "name": ["наимен", "товар"],
      "qty": ["колич"],
      "comment": ["комментар", "примеч", "помет", "замет"]
    }
  }
}
```

## 4. Поля профиля (что означает каждое)

1. `label`  
   Человекочитаемое имя в выпадающем списке.

2. `description`  
   Короткая подсказка под селектором профиля.

3. `code_pattern`  
   Regex для распознавания кода позиции (в основном для Excel).

4. `doc_pattern`  
   Regex для извлечения номера/даты документа из имени файла и начала текста.

5. `row_start_pattern`  
   Regex начала строки позиции в PDF.

6. `qty_pattern`  
   Regex извлечения количества из текстовой строки позиции.

7. `stop_prefixes`  
   Префиксы строк, после которых парсинг позиций в PDF останавливается (например блок "Итого").

8. `excel_headers`  
   Подсказки по заголовкам столбцов Excel:
   - `code` - где искать код,
   - `name` - где искать название,
   - `qty` - где искать количество,
   - `comment` - где искать комментарии.

Поиск заголовков в Excel делается по принципу "содержит подстроку".

## 5. Пример: добавление нового профиля

Допустим, новый поставщик присылает формат:

- код как `DOC-000123`;
- количество помечено как `pcs`;
- в Excel столбец называется `Item code`.

Тогда в `data/parser_profiles.json` добавляем:

```json
{
  "poscenter": {
    "label": "POScenter",
    "description": "Базовый профиль для текущих выгрузок POScenter/УП."
  },
  "new_vendor_2026": {
    "label": "New Vendor 2026",
    "description": "Профиль для выгрузки поставщика 2026.",
    "code_pattern": "^(?:DOC-\\d{6}|\\d{6,})$",
    "doc_pattern": "(?:No\\.?\\s*)?(DOC-\\d+).*?(?:Date\\s+(\\d{2}[.]\\d{2}[.]\\d{4}))",
    "row_start_pattern": "^(\\d+)\\s+((?:DOC-\\d{6})|(?:\\d{6,}))\\s*(.*)$",
    "qty_pattern": "(.+?)\\s+(\\d+(?:[,.]\\d+)?)\\s*pcs(?:\\s|$)",
    "stop_prefixes": ["Total", "Issued by:", "Received by:"],
    "excel_headers": {
      "code": ["item code", "code"],
      "name": ["item name", "name"],
      "qty": ["qty", "quantity"],
      "comment": ["comment", "note"]
    }
  }
}
```

Дальше:

1. сохранить `parser_profiles.json`;
2. в приложении выбрать профиль `new_vendor_2026`;
3. нажать `Обновить`.

После переключения профиль применяется к новому пересканированию индекса.

## 6. Рекомендуемый безопасный порядок изменений

1. Никогда не удаляй `poscenter`.
2. Скопируй `poscenter` в новый профиль и меняй только копию.
3. Меняй по одному правилу за раз.
4. Проверяй на 2-3 реальных документах.
5. Если что-то пошло не так - вернись на `poscenter`.

## 7. Типовые проблемы и что править

1. **Ноль позиций в Excel**  
   Обычно проблема в `excel_headers` (не совпали заголовки колонок).

2. **Все количества = 1**  
   Не подошел `qty_pattern`.

3. **Не извлекается номер/дата документа**  
   Нужна правка `doc_pattern`.

4. **В PDF строка с позицией не распознается**  
   Нужна правка `row_start_pattern`.

5. **Ошибка Unknown profile**  
   Профиль не найден в `parser_profiles.json` (или JSON поврежден).

## 8. Мини-чек после создания профиля

1. Профиль появился в выпадающем списке.
2. После выбора и `Обновить` документы читаются без ошибок.
3. Количество/коды/названия совпадают с оригиналом.
4. В таблице есть ожидаемые позиции и статусы сканирования работают как обычно.
