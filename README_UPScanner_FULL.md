# UP Scanner / scan_YP.dc

Локальная программа для сверки оборудования по PDF/XLSX документам в папках `Acts/new` и `Acts/old`.
Запускается как `UPScanner.exe`, открывает веб-интерфейс в браузере и работает с локальными файлами рядом с exe.

## Быстрый старт

1. Положи новые документы в `Acts/new`.
2. Запусти `UPScanner.exe`.
3. Выбери один или несколько документов слева.
4. Сканируй код в поле `Сканируй код сюда` или сканером.
5. Программа увеличивает количество найденной позиции, подсвечивает последнюю позицию и прокручивает к ней.
6. Когда документ или проект готов, используй `В old` или `Завершить проект`.

## Папки рядом с exe

- `Acts/new` - новые документы для проверки.
- `Acts/old` - завершенные или архивные документы.
- `Acts/exports` - экспорт и печатные материалы, если используются.
- `data` - база индекса, проекты, прогресс, комментарии, настройки парсинга.
- `_internal` - служебные файлы приложения, руками не редактировать.

## Документы

Поддерживаются:

- `.pdf`
- `.xlsx`
- `.xlsm`

Программа ищет коды вида `УП-...` и цифровые коды, собирает позиции, количество, название, документы-источники и комментарии.

## Проекты

Проект нужен, чтобы сохранять прогресс не только по выбранному документу, но и по группе документов.

Возможности:

- назначить проект выбранным документам;
- переименовать проект без потери прогресса;
- отвязать документы от проекта;
- открыть проект из списка проектов;
- завершить проект и перенести документы в `old`.

Если переименовать папку или документ вручную, программа может считать это новым объектом. Для переименования проекта лучше использовать кнопку `Переименовать` в интерфейсе.

## Сканирование

Есть несколько режимов ввода:

- ручной ввод в поле `Сканируй код сюда`;
- USB HID сканер, который работает как клавиатура;
- COM/VCOM сканер через последовательный порт;
- виртуальная клавиатура в интерфейсе.

### Ручной ввод

Верхнее поле ввода считается ручным вводом.

По умолчанию настройки обрезки сканера к нему не применяются. Например, если в настройках сканера стоит убрать 2 символа спереди и 2 сзади, ручной ввод `5726` останется `5726`.

Если нужно проверить ручной ввод как сканерный, включи галочку:

`Применять обрезку к ручному вводу`

### USB HID

USB HID сканер обычно выглядит для браузера как клавиатура.

Программа ловит быстрый ввод, заканчивающийся `Enter`, и считает это сканером. Для такого ввода применяются настройки сканера: обрезка символов спереди/сзади.

В настройке сканера есть диагностика USB/HID:

- последнее событие `keydown/keyup`;
- `event.key`;
- `event.code`;
- `repeat`;
- интервал между Enter;
- предупреждение `похоже на двойной Enter`, если Enter пришел два раза подряд слишком быстро.

Важно: браузер обычно не показывает сырые байты USB HID как `CR` и `LF`. Он показывает уже клавишу `Enter`.

### COM/VCOM

Для COM сканера выбери режим `VCOM`, порт и скорость, затем нажми `Старт`.

Для VCOM программа читает сырые байты пакета, поэтому в диагностике видно:

- `CR`;
- `LF`;
- `CR+LF`;
- сколько раз пришло окончание строки;
- последний пакет.

Если сканер отправляет `CR+LF`, программа покажет это как `CR: 1`, `LF: 1`, `конец: CR+LF`.

## Настройки сканера

Открой `▸ Настройки`, затем кнопку `Сканер`.

В окне настройки можно:

- сканировать тестовый код;
- видеть `raw`;
- видеть строку после обрезки;
- видеть `cleaned`;
- видеть тип, например `EAN13` или `8 цифр`;
- убрать N символов спереди;
- убрать N символов сзади;
- включить или выключить обрезку для ручного ввода;
- проверить Enter/CR/LF.

Правило по умолчанию:

- VCOM - обрезка применяется;
- USB HID быстрый скан - обрезка применяется;
- ручное поле ввода - обрезка не применяется;
- виртуальная клавиатура - обрезка не применяется;
- тестовое окно сканера - обрезка применяется, чтобы проверить настройки.

## Поиск и совпадения

Если введенный текст не является кодом, программа ищет по названию позиции.

Пример: если ввести `весы`, будут показаны позиции, где в названии есть `весы`.

Если найдено несколько совпадений:

- `↑` и `↓` выбирают вариант;
- `Enter` подтверждает выбранный вариант;
- клавиши `1-9` сразу выбирают вариант по номеру.

Это работает даже если фокус стоит в поле `Сканируй код сюда`.

## Изменение количества

Последнюю отсканированную позицию можно поправить:

- `→` увеличивает количество на 1;
- `←` уменьшает количество на 1;
- кнопки `+` и `-` в строке позиции меняют количество;
- в виртуальной клавиатуре есть `+1` и `-1`.

Стрелки `←/→` работают и когда фокус стоит в основном поле сканирования.

## Виртуальная клавиатура

Кнопка `Клавиатура` открывает плавающую клавиатуру.

Она не сдвигает таблицу вниз и лежит поверх интерфейса.

Кнопки:

- цифры и `УП-`;
- `⌫` удалить символ;
- `C` очистить;
- `Enter` отправить код;
- `-1` уменьшить последнюю позицию;
- `+1` увеличить последнюю позицию;
- стрелки в верхней части перемещают клавиатуру влево/вправо.

## Скролл

Скролл один общий для страницы.

Кнопки справа снизу:

- `↑` наверх;
- `↓` вниз.

При сканировании программа старается прокрутить страницу к найденной позиции.

## Подсветка и ошибки

Последняя отсканированная позиция помечается рамкой и точкой.

Если код не найден:

- запись появляется в логе `Не найдено`;
- показывается крупный сплэш `Код отсутствует`.

## Профили парсинга

Профиль разбора определяет правила чтения PDF/XLSX.

Если документ выглядит иначе и позиции не распознаются, проверь профиль в настройках.
Подробности по профилям могут быть в `PARSER_PROFILE_GUIDE.md`, если файл лежит рядом с exe.

## Что делать, если сканер считает два раза

Открой `Настройки` -> `Сканер` и просканируй тестовый код.

Для USB HID смотри:

- `USB/HID Enter`;
- интервал между Enter;
- предупреждение `похоже на двойной Enter`.

Для COM/VCOM смотри:

- `CR`;
- `LF`;
- `конец`;
- `Enter`.

Если COM показывает `CR+LF`, а скан считается два раза, настрой сканер на один суффикс: только `CR`, только `LF` или только `Enter`, либо сообщи разработчику, какой пакет виден в диагностике.

## Безопасность данных

Программа работает локально.

Не удаляй вручную папку `data`, если нужен прогресс проектов.
Перед экспериментами можно скопировать всю папку `scan_YP.dc` целиком.

## Запуск из исходников

Для разработки используется `main.py`.

Обычно:

```powershell
python main.py --no-browser --no-tray --port 8765
```

После запуска открой:

```text
http://127.0.0.1:8765
```

Для сборки exe используется `build_scan_YP.dc.ps1`.
