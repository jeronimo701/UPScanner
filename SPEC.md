# Сканирование УП: рабочая спецификация

## Запуск
- Приложение запускается с иконкой в системном трее.
- Через трей можно открыть страницу приложения в браузере.
- Через трей можно полностью выйти: HTTP-сервер и VCOM-чтение должны корректно останавливаться.
- Обычный запуск должен идти без видимых PowerShell/CMD-окон и без висящих терминалов.
- Единственный способ запуска: `python main.py`.
- Проверки запуска и остановки выполнять короткими командами с timeout, без зависания долгих процессов.

## Документы
- Рабочая папка: `Acts`.
- Новые документы лежат в `Acts/new`.
- Завершенные документы переносятся в `Acts/old`.
- Поддерживаются PDF и Excel (`.xlsx`, `.xlsm`).
- Из документов нужны:
  - номер документа или номер + дата;
  - код УП, включая шестизначные коды;
  - название оборудования;
  - количество;
  - комментарий/примечание, если есть.

## Интерфейс
- Показывать список документов из `new` или `old`.
- Можно выбрать один или несколько УП/актов.
- Можно закрепить за документом мини-проект/название для будущего поиска и просмотра.
- Из выбранных документов собирается общий список оборудования.
- У каждой позиции показывается, из какого документа она пришла, и встречается ли в нескольких документах.

## Сканирование
- HID keyboard: браузер принимает ввод сканера как клавиатуру, обычно с `Enter`.
- VCOM/COM-порт: Python читает порт через `pyserial`.
- Нужен быстрый выбор режима HID/VCOM.
- Для VCOM нужны настройки порта и скорости.

## Статусы
- Зеленый: найдено и количество совпало.
- Желтый: найдено, но еще не все количество.
- Красный: лишний скан или код не найден.
- Отдельно показывать счетчик вида `отсканировано 1 / нужно 2`.

## Финализация
- В конце собранные/отредактированные документы можно сохранить для печати или передачи.
- Старые работы из `Acts/old` можно просматривать.
