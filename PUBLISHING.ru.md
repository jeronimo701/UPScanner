# Проверки публикации: UPScanner

Дата: 2026-10-22. Исходные пользовательские папки и готовые прежние пакеты не изменялись.

- Подготовлена отдельная копия исходников. Сохранённые документы, база/состояние пользователя, логи, кэши, старые архивы и рабочие данные исключены.
- Переписан только безопасный рецепт сборки: он не копирует рабочие данные, не удаляет каталоги и требует новый выход. Программная логика сохранена.
- Собран новый Windows x64 onefile EXE из этих исходников, Python 3.13.12 / PyInstaller 6.19.0. EXE, материалы пользователя и крупные зависимости в Git не добавляются. В Git находятся исходники, ресурсы, документация, manifests и notices.
- Собственная лицензия и сторонние notices включены внутрь EXE и лежат рядом. Точная среда записана в SOURCES.json и requirements-build.txt.
- Gitleaks исходной подготовленной копии: находок нет. Для итогового дерева выполняется повторная проверка перед отправкой.
- Готовый EXE запущен в отдельной пустой папке с кириллицей, с отключённым открытием браузера. Все созданные данные остались в тестовой папке. Пользовательская установка и исходные рабочие документы не использовались.
- PASS: frozen EXE, HTTP ping, HTML/JS/CSS, пустой список документов, состояние serial без открытия физического порта, чистое завершение через локальный API, exit 0. В сборочном логе были предупреждения о недоступных macOS frameworks из pyserial; на Windows не используются.
- Не проверены: реальное сканирование HID/VCOM, совместимость физических устройств, разбор всех разновидностей документов и фактическая печать.

Контрольная сумма итогового EXE: SHA256SUMS.txt. Публикация — private GitHub, prerelease snapshot-2026-10-22. Исходная лицензия не является общей лицензией на сторонние компоненты.
