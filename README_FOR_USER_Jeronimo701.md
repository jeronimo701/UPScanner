# UP Scanner — руководство пользователя

Это приложение подготовил **Jeronimo701** для проверки оборудования по УП/актам.

## 1) Как запускать

1. Открой папку сборки `scan_YP.dc`.
2. Запусти `UPScanner.exe`.
3. Приложение откроется в браузере.
4. В трее (иконка рядом с часами) доступны:
   - `Открыть приложение` (обычный браузер),
   - `Kiosk mode (Edge/Chrome)`,
   - `Выход`.

## 2) Структура папок рядом с exe

- `Acts\new` — новые документы.
- `Acts\old` — завершённые проекты.
- `Acts\exports` — экспортированные файлы (если используются серверные экспорты).
- `data` — служебные данные приложения (проекты, прогресс, комментарии, индекс).

Важно: **не удаляй папку `data`**, если нужно сохранить историю и прогресс.

## 3) Базовый рабочий сценарий

1. Положи документы (`.pdf`, `.xls`, `.xlsx`, `.xlsm`) в `Acts\new` или загрузи через кнопку в интерфейсе.
2. Выбери документы слева.
3. При необходимости укажи `Мини-проект / название` и нажми `Применить`.
4. Сканируй коды:
   - HID: просто сканируй как клавиатурой.
   - VCOM: в настройках выбери `VCOM`, COM-порт, `Старт`.
5. Проверяй цвет статуса:
   - зелёный — готово,
   - жёлтый — частично,
   - красный — лишнее/ошибка.
6. По завершении:
   - `В old` — перенести один документ,
   - `Завершить проект` — закрыть весь проект и перенести в `Acts\old\...`.

## 4) Экспорт и печать

В меню настроек:

- `Скачать HTML` — скачать чистую печатную версию.
- `Скачать PDF` — скачать PDF из clean-render (с кириллицей).
- `Печать` — открыть отдельную чистую страницу для печати.

## 5) Если нужно исправить количество вручную

В таблице у каждой позиции есть `-`, поле количества, `+`.
Можно уменьшить/увеличить/ввести вручную и нажать Enter.

## 6) Виртуальная клавиатура

- Кнопка `Клавиатура` открывает цифровую панель.
- Кнопки `⇦` и `⇨` двигают панель влево/вправо.
- В настройках можно изменить текст и ввод спец-кнопки префикса (по умолчанию `УП-`).

## 7) Что сохраняется между перезапусками

- тема (светлая/тёмная),
- выбранный раздел (`new/old`),
- режим сканера (`HID/VCOM`),
- скорость порта (`baudrate`),
- положение клавиатуры (влево/вправо),
- префикс спец-кнопки клавиатуры.

## 8) Перенос на флешку / другой ПК

Приложение сделано переносимым:

- Все рабочие пути считаются **от папки, где лежит `UPScanner.exe`**.
- Можно копировать всю папку `scan_YP.dc` в любое место (включая флешку).
- После переноса структура должна оставаться такой же (`UPScanner.exe`, `Acts`, `data`, `_internal`).

## 9) Возможные проблемы

1. `Скачать PDF` не работает:
   - на ПК может не быть Edge/Chrome, или headless-режим заблокирован политикой.
   - временное решение: использовать `Скачать HTML` + печать в PDF средствами браузера.

2. Не видно COM-порт:
   - проверь драйвер сканера,
   - переподключи устройство,
   - обнови список/перезапусти приложение.

3. Кнопка в трее не видна:
   - раскрой скрытые иконки рядом с часами Windows.

## 10) Техническая поддержка

Если нужен новый режим/логика, в описании запроса приложи:

- пример файла УП,
- что ты нажал,
- что ожидал,
- что получилось фактически.
