# UPScanner для Android

Автономная версия для складской сверки, Android 7.0+ с обновлённым Android System WebView. Сервер Windows, интернет и аккаунт для работы не нужны. Камера нужна только для сканирования с телефона.

## Установка и обновление
Откройте `UPScanner.apk` на телефоне и подтвердите установку. При обновлении установите APK поверх старой версии: удаление приложения и очистка данных стирают проверки. Начиная с версии 1.3 данные пишутся во внутреннее хранилище приложения. Если сведения из старой версии ещё доступны, они переносятся автоматически при первом запуске. Уже сброшенные сведения не восстанавливаются.

## Проекты и накладные
- Выберите «Проекты» → «Новый проект», введите своё название и нажмите «Создать». Можно также нажать «＋» рядом с выбором проекта или начать с проекта «Основная».
- Список рядом с кнопкой «Проекты» переключает текущую проверку. В «Проектах» можно переименовать выбранный проект, отправить в архив, вернуть из архива или удалить с подтверждением. Переименование и архив не стирают результаты.
- Через «Накладные» выберите PDF, XLS или XLSX. В Excel нужны колонки кода и количества; наименование и комментарий считываются при наличии. PDF должен содержать текст, а не только фотографию или скан: распознавания изображений нет. Если количество в PDF не удалось прочитать, подставляется 1, а предупреждение видно в списке документов. Одинаковые коды суммируются.
- Чтобы передать вложение из почты, Telegram или «Файлов», выберите нужный проект, затем у файла нажмите «Поделиться» → «UPScanner». Передаётся сам файл, не ссылка на сообщение или облако. Если приложение не предлагает поделиться файлом, скачайте его и выберите через «Накладные».

## Проверка
- Введите код и нажмите «Ввод»/Enter, либо используйте камеру. Сканер в режиме клавиатуры работает с фокусом в поле ввода и суффиксом Enter. Можно искать по окончанию кода или названию. Подтверждение совпадения прибавляет одну единицу.
- Кнопки «−», «＋» меняют факт. «Брак» и F8 помечают позицию, повторное нажатие снимает отметку. Если цифрового кода нет в накладных, его можно добавить отдельно.
- Готовые позиции уходят вниз. Через «Расхождения» доступны брак, лишнее и отсутствующие коды; недобор виден в «Осталось».
- Кнопка со стрелкой выгружает CSV UTF-8. Этот отчёт можно открыть в Excel. Накладные, результаты и выбранный проект сохраняются автоматически, в том числе после закрытия приложения.

## Настройки
Кнопка справа от «Накладные» открывает настройки и краткую инструкцию. Доступны светлая, тёмная и AMOLED-темы; AMOLED использует чёрный фон. «Обрезка кода» позволяет убрать до 64 символов с начала и с конца кода. По умолчанию обрезка применяется только при чтении камерой. Для ручного ввода и сканеров, которые работают как клавиатура (HID), есть отдельная галочка. «Сбросить результаты» с подтверждением очищает количество, брак и пересорт только в текущем проекте; накладные остаются.

## Отличия от Windows
COM-порт не поддерживается. История и проекты Windows автоматически не переносятся и не синхронизируются.

## Сборка
Откройте папку в Android Studio или выполните `.\gradlew.bat assembleDebug` с JDK 17, Android SDK 35 и переменной `ANDROID_HOME`. APK появится в `build/outputs/apk/debug/`. Первая сборка скачивает Gradle 8.11.1, AndroidX, ZXing, [PDFBox-Android](https://github.com/TomRoush/PdfBox-Android) и [JExcelAPI](https://jexcelapi.sourceforge.net/). Отладочный APK предназначен для установки вручную, не для Google Play.

Для проверки интерфейса: `node tests/ui.cjs` с установленными Playwright и Chromium.

Если на этом Windows-компьютере JDK выдаёт `Unable to establish loopback connection`, задайте для текущего сеанса PowerShell `$env:JAVA_TOOL_OPTIONS = '-Djdk.net.unixdomain.tmpdir=C:\upscanner-nonexistent-socket-dir'` и повторите сборку. Не создавайте указанный каталог: параметр нужен, чтобы JDK вернулся к TCP loopback.
